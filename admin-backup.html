Backup & Recovery

Admin only. Back to admin panel

1. Download a backup

Includes every customer, account, transaction, deposit, withdrawal, card and notification. It also contains hashed passwords and PINs, so keep the file private.

The HTML file opens in any browser as a readable customer list, and it is also a full backup you can restore from.

2. Restore from a backup

Pick a backup file (HTML or JSON, or an export from the old Cloudflare site). Existing customers are never overwritten or duplicated: people are matched by email, accounts by account number. Only missing records are added.


The server also saves its own copy daily on the volume under /data/backups (last 14 days).
